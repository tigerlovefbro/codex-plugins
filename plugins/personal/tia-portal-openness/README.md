# tia-portal-openness

Siemens TIA Portal V21 自动化技能：通过 Openness API（PowerShell / .NET Framework 4.8）打开项目、枚举设备/PLC 块、导出/编译、读写 tag table。无需 .NET SDK。

## 文件
- `skills/tia-portal-openness/SKILL.md`：核心技能（接入方法 + API + 坑）。
- `skills/tia-portal-openness/scripts/open_portal.ps1`：可运行模板。
- `skills/tia-portal-openness/references/openness-api-reference.md`：API 细节。

## 前提
本机需安装 TIA Portal V21 且有有效许可证（Openness 依赖 TIA Portal 实例）。
