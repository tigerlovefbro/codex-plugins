# Unity Agent Skills

8 个 Unity 6.3 LTS 通用开发技能，收录自 [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)（Apache-2.0，6.9k+ stars）。

## 技能清单

| 技能 | 说明 |
| --- | --- |
| unity-animation | Animator/Mecanim：状态机、过渡、参数、混合树、动画层、人形 Avatar IK |
| unity-build-pipeline | 构建管线与 CI 脚本 |
| unity-csharp-scripting | C# 脚本：生命周期、协程 |
| unity-input-system | 新输入系统与按键重绑定 |
| unity-navmesh | NavMesh 寻路 |
| unity-physics | 物理：射线检测、关节 |
| unity-scriptableobjects | ScriptableObject 与事件通道 |
| unity-tilemap-2d | 2D Tilemap 瓦片地图 |

目标版本：Unity 6.3 LTS（6000.3）。
